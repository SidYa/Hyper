# Hyper

Fast and light game launcher for Epic and GOG games. 
Inspired by and build-conceptually based on Heroic Games Launcher, but with all core mechanics, backend, and logic completely rewritten in Rust for maximum speed, minimal memory footprint, and instant responsiveness.

- One Unified Library: Access both your Epic Games and GOG libraries in one place.
- Full Game Management: Easily install, update, uninstall, and launch games.
- Built-in Stores: Seamless access to Epic and GOG stores with unified login.
- Console Mode: TV-friendly UI fully optimized for controllers.
- Security First: User credentials remain securely encrypted and stored locally on disk.
- Cross-Platform: Native support for Windows and Linux (including Steam Deck).
